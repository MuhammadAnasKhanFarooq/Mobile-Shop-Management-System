# Mobile Shop Management System

A basic first-semester desktop application developed as an early programming project for mobile shop management.

The project was created to practice basic C++ programming, Qt-based user interfaces, and simple data-management operations.

## Features

- Add mobile records
- View mobile records
- Delete mobile records
- Add customer records
- View customer records
- Delete customer records
- Basic graphical user interface

## Technologies Used

- C++
- Qt
- Qt Designer
- QMake

## Project Structure

The project includes separate windows and modules for:

- Adding mobiles
- Deleting mobiles
- Viewing mobiles
- Adding customers
- Deleting customers
- Viewing customers
- Main application window

## How to Run

1. Clone or download this repository.
2. Open `MobileShopManagementSystem.pro` in Qt Creator.
3. Configure a compatible Qt kit.
4. Build and run the project.

## Project Background

This was developed as an academic project during the first semester of BS Information Technology.

It was one of my earliest desktop application projects and was created mainly to practice basic C++ and GUI development.

AI-assisted development was used for parts of the implementation.
